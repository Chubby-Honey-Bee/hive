A correct design decides: flag parsing that takes a value argument (`-n 3`), rejects a negative or non-numeric N and the two flags together; a line reader that keeps the newline (`bufio.Reader.ReadString('\n')` or a scanner that re-adds it) and prints a last unterminated line as is; byte mode with `io.CopyN` or `io.LimitReader`; headers only when two or more files are named, with the blank separator before every header but the first; the error path that continues and exits 1. The twin, cli-wc, counts instead of printing; a design that ignores the statement fails one of the two.
