A correct design decides: a line scanner (`bufio.Scanner`) with a line counter that counts skipped lines too; a current-section string prefixed with a dot to each key; splitting on the first `=` only (`strings.Cut`); a `*ParseError` returned as a pointer so `errors.As(err, &pe)` finds it; last-wins on duplicates, which a plain map assignment gives; and a non-nil empty map for empty input. The twin, kv-quoted, has no sections, rejects duplicates and unquotes values; a design that ignores the statement fails one of the two.
