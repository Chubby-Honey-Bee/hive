A correct design decides: hand-rolled flag parsing (the `flag` package stops at the first non-flag too, but its error output differs; either works if usage goes to stderr with exit 2); one counting function over an `io.Reader` returning the three counts, called for stdin or for each file; the fixed l-w-c column order independent of flag order; an error path that records exit 1 and continues; the total line only for two or more files; output formatting with single spaces. The twin, cli-head, prints file contents with headers instead of counts; a design that ignores the statement fails one of the two.
