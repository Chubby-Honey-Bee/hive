A correct design decides: copy the slice (normalising each interval while copying) and sort the copy, never the input; the merge condition `iv.Lo <= cur.Hi + 1` for closed integer ranges (touching and adjacent both merge); extend `cur.Hi` only when the new `Hi` is larger (nested intervals); and that normalisation happens before sorting, since sorting by an un-normalised `Lo` breaks the sweep.
